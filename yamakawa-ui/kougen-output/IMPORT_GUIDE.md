# Import guide: 櫻坂46「光源」PV 巡礼マップ

## Recommended My Maps import

1. Open https://www.google.com/maps/d/ and create a new map.
2. For each layer below, add a layer and import the matching CSV file.
3. If coordinates are present, choose Latitude and Longitude as location columns. Otherwise choose Address.
4. Choose Name as the title column.

## Layer import order

- 1. `layers/01_pv-fika-lounge.csv` - 光源 PV - FIKA Lounge 南行徳
- 2. `layers/02_pv.csv` - 光源 PV - 行徳送電塔
- 3. `layers/03_pv.csv` - 光源 PV - 鹿島製造所

## Single-file preview

Import `yamakawa-ui-kougen_all_layers.kml` if you want a single KML preview with folders per layer.
